What this is not

  • The window is the last {{hero.prints}} prints, not 24 hours — {{hero.span}} h on this pair, {{hero.coverage}} of its 24h transactions. Every row states its span.
  • Uniswap v3 fee tiers of one pair merge — the feed carries no pool address; a row marked ×n is n pools sharing (venue, base, quote).
  • Quote-to-fill is a realised print-to-print move, adverse-signed, fee-inclusive: on a 0.30 % pool consecutive opposite-side prints straddle the fee twice, so its p90 sits near 60 bps. It is used comparatively, across pools of one token in one window.
  • A round-trip is a shape, not a verdict — same wallet, same block, opposite sides, size-matched. The page prints the rows and the definition, never a label on a person.
  • The paste box shares one IP against the anonymous rate limit — a 429 is shown as a 429 with the command to run instead. This table was rendered from a committed run; the CLI is the primary live path.
