A keyless 200 carries Allow-Headers, Allow-Methods and Max-Age — and not Access-Control-Allow-Origin. The browser discards a body it already has. Every web tool on /public-api needs a proxy; this one's is /api/swaps, which also puts every visitor behind one IP.

Questions a judge will ask

Honest limits.

Is this page live?

The table is rendered from a committed run, captured {{hero.captured}}, and says so on every number. The paste box is live: it runs the same engine in the browser on rows fetched through a keyless proxy. The proxy shares one IP against a per-IP anonymous limit, so a 429 is shown as a 429 with the command to run instead — the CLI is the primary live path, and every reader has their own quota there.

How wide is the window?

The last {{hero.prints}} prints, not 24 hours — {{hero.span}} h on the hero pair, {{census.longest_span}} h on {{census.longest_symbol}}. The span is on every row, and the receipt carries the window's share of the pool's 24 h transactions ({{hero.coverage}} here).

Is a round-trip a verdict on a person?

No. It is a shape: same wallet, same block, opposite sides, size within 5 %. The page prints the rows and the definition, never a label on a person. A router contract can appear as one maker for many users; the number is "the same address on both sides", exactly as the API reports it, and nothing more is claimed.

Why does p90 sit near {{hero.organic_p90}} bps on the routed pool?

Quote-to-fill is a realised, fee-inclusive print-to-print move: on a 0.30 % pool two consecutive opposite-side prints straddle the fee twice, so p90 lands near 60 bps on every busy v2 pool. It is used comparatively, across the pools of one token in one window, where that bias is shared — which is also why the rule prefers the 0.05 % tiers when they are deep enough.

Why is a pool marked ×2 or ×3?

The feed carries no pool address, so pools are recovered from (venue, base, quote). Uniswap v3 fee tiers of one pair share that key and merge; a row marked ×n is n pools, and its number is per pair, not per tier. Filed as a finding in FEEDBACK.md.

What is not built?

No prediction, no wallet labelling, no composite score, no alerts, no watchlists, no key. The product names the middleman and says where to route; that verb is the whole scope. When no pool clears the routing floor the rule is printed, never widened.
